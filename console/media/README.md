# console/media — 🎬 DEMO-0904 시연용 실사 클립

여기에 **`robot_view.mp4`** 를 넣으면 관제·영상·비상 화면의 카메라 자리에서 재생된다.
파일이 없으면 자동으로 `CAMERA` 자리표시로 되돌아간다 — 없다고 화면이 깨지지 않는다.

## 촬영

로봇에 카메라를 붙이고 **연결복도 통과 구간**을 찍는다 (bag `realtake6` 163.0~214.3초).
관제 화면 녹화는 `--at 180` 부근에서 하므로, 클립은 그 장면과 방향이 맞아야 한다.

```
길이     3~5초면 충분하다 (재생은 자동으로 반복된다)
방향     🔴 전방. 카메라는 앞을 보고 대피자는 뒤에 있다 — 사람이 찍히면 화면과 어긋난다
진행     🔴 위 복도 → 아래 복도 (bag 180초에 로봇이 가는 방향)
           163.0s 진입 (8.94, -1.26) · 188.7s 중간 (9.02, -5.35) · 214.3s 이탈 (8.91, -9.50)
비율     16:10 에 맞춰 잘리므로 가운데에 여백을 두고 찍는다
음성     쓰지 않는다 (muted 재생)
```

## 🔴 촬영 장비 — 휴대폰·별도 카메라를 쓴다

**Orbbec·열화상 ESP32 를 젯슨에 꽂고 주행하면 안 된다** — 라이다가 죽는다(예약 66,
`CURRENT_HANDOFF` 금지 범위). 이 클립에 필요한 것은 *"로봇 시점 그림"* 이지
*"로봇이 처리한 영상"* 이 아니므로, **휴대폰을 로봇에 고정해 찍으면 예약 66 과 무관하다.**

🔵 자율주행도 필요 없다 — **손으로 밀면서 찍어도 결과가 같다.** 관제 화면은 bag 이
돌리므로 클립은 그 복도를 그 방향으로 지나가는 그림이기만 하면 된다.
구동부 무장·E-stop·Nav2·SLAM 이 전부 불필요해진다.

## 넣기

```bash
cp <찍은파일> ~/ros2_ws/console/media/robot_view.mp4
# 브라우저 새로고침이면 끝
```

포맷이 안 맞으면 변환:

```bash
ffmpeg -i 원본.mov -c:v libx264 -crf 22 -pix_fmt yuv420p -an \
       -vf "scale=1280:-2" console/media/robot_view.mp4
```
