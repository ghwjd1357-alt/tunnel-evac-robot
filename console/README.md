# console — 관제 시스템 (Operator Console)

> ROS 패키지가 아니다. colcon 빌드와 무관한 일반 폴더.
> 같은 저장소에 두는 이유 = 토픽 계약과 한 커밋으로 원자적 동기화.
> 설계 정본 = `~/Desktop/개발현황/0718_관제시스템.md` + 이 파일.
> **2026-09-02~04 전면 개편** — 구판은 `legacy/index_0719.html`.

## 실행

```bash
# 실차·시뮬과 함께
bash console/run_console.sh

# 로봇 없이 08-23 실차 기록으로 (촬영·개발에 이걸 쓴다)
bash console/run_console.sh --bag realtake6 --loop

# 🎬 촬영 — 브라우저가 화면을 연 **그 순간** 부터 재생한다
bash console/run_console.sh --bag realtake6 --at 163 --on-connect
```

🔴 `--on-connect` 가 없으면 명령을 친 시점부터 bag 이 흐른다. 주소를 입력하고 화면이 뜨는
사이에 로봇이 지나가 버려 **지도와 카메라 영상이 어긋난다**(09-04 촬영에서 실제로 어긋났다).
`console/wait_client.py` 가 `/client_count` 를 보고 접속을 기다리며, 직전 테이크의 탭이
남아 있어도 되도록 **수가 늘어나는 순간**을 본다.

🔴 시작할 때 이전 실행의 `bag play`·rosbridge·웹서버를 **먼저 죽인다.** 안 그러면 bag 이
둘 돌아 지도가 순간이동한다 (`PITFALLS §20-④`).

| 주소 | 화면 |
|---|---|
| `http://localhost:8000` | 관제 |
| `http://localhost:8000/?display=1` | 로봇 몸통 디스플레이 (7인치 1024x600) |

사전 1회 `sudo apt install ros-humble-rosbridge-suite`.

🔴 `--bag` 은 **재생**이다. 실시간 주행이 아니다. 영상·문서에 "실시간"으로 쓰지 않는다.

## 관제 모드 — 평시 / 대응 / 긴급

색만 바뀌는 게 아니라 **패널 내용 자체가 바뀐다.**

| 모드 | 상태 | 왼쪽 패널이 보여주는 것 |
|---|---|---|
| **평시 감시** | PATROL · ESCAPED | 로봇이 정상인가 — 구동부·비상정지·라이다·통신 |
| **화재 대응 중** | APPROACH·SCAN_AREA·GATHER·GUIDE·HOLD·SEARCH_BACK | 사건이 어떻게 되어가나 — 화재 위치·대피자·싸이렌·주행 |
| **즉시 개입 필요** | FAULT·BLOCKED·RESCUE·NO_VICTIM | **무엇을 해야 하는지** 지시문 |

구현 = `body[data-mode]` 한 줄 + CSS. JS 는 스타일을 직접 만지지 않는다.

🔴 **경과·이동거리는 구간 기준이다** — 대응은 **화재 감지(/alarm) 시점**부터, 순찰은 순찰 진입부터.
순찰은 무한 루프라 관제 접속 시점부터 재면 아무 의미가 없다.

## 설계 규칙

**색** — ISA-101 산업 HMI: 바탕은 회색조, 색은 이상 상태에만.
평상시가 무채색이어야 경보 하나가 눈에 띈다. 정의는 `css/tokens.css` **한 곳뿐**.

**금지** — 이모지 · 그라디언트 · 그림자 · 둥근 모서리(2px 초과) · 아이콘 남발.
숫자·좌표·시각은 고정폭(`--mono`) + 오른쪽 정렬. 자리수가 흔들리면 안 된다.

**말** — 한글을 크게, 코드값은 작게 병기. 대응표 = `js/i18n.js`.
디스플레이는 **대피자가 읽는 말**을 따로 쓴다(`GUIDE` → "따라오세요").

**글꼴** — 나눔고딕. Noto Sans CJK KR 은 어디에나 기본이라 "아무 설정 안 한 화면"으로 읽힌다.
둘 다 로컬에 있어 인터넷 없이 동작한다.

```
js/map.js           지도 canvas — 정리·좌표변환·렌더
js/mission.js       관제 화면       js/video.js    영상·의사소통
js/diag.js          진단 화면       js/record.js   기록 화면
js/emergency.js     비상 원격 조종  js/alert.js    ★ 경보 규칙 10종

wait_client.py      촬영용 — 브라우저 접속을 기다렸다가 bag 을 시작
```

🔴 `serve.py` 는 `Cache-Control: no-store` 를 보낸다. 브라우저가 낡은 모듈과 새 모듈을
섞어 물면 **화면이 아무 오류 없이 "연결 대기"로 죽는다** (`PITFALLS §20-③`).

**빌드 도구를 쓰지 않는다.** ES 모듈이라 브라우저가 `import` 를 직접 처리한다.
시연 당일 "빌드가 안 된다"는 실패 모드를 만들지 않기 위한 선택이다.

## 지도를 어떻게 정리하는가

🔴 **벽의 모양은 한 픽셀도 건드리지 않는다.** 문 오목부·기둥·요철은 로봇이 실제로 그린
구조이고 그것이 이 지도의 증거력이다. 지우는 것은 "벽이 아닌 것"뿐이다.

| | 기준 | 근거 | 실측(realtake6) |
|---|---|---|---|
| ① | 미탐사(-1) → 투명 | 정보가 0인 영역이 화면 72.5% 를 먹었다 | 190,940 셀 |
| ② | 고립 점유셀 제거 (이웃 ≤1) | 반사 노이즈. 문 요철은 이웃이 많아 안 걸린다 | 벽의 5.4% |
| ③ | 비구조물 점 무리 제거 (<40셀 = 2 m) | 유리 너머·동적 장애물. 벽 한 줄은 165~415셀 | 벽의 17.6% |
| ④ | **양쪽 벽 사이만 복도** | 복도 끝에서 한쪽 벽이 끊기면 그 바깥은 복도가 아니다 | 자유공간 55.8% |
| ⑤ | 임무 운용 구역 밖 제외 | `waypoints_real_H.yaml corridor_graph` 기준 | x −1.0~14.5 · y −12.5~1.4 |

결과: 그리는 범위 34.2×18.2 m → **16.0×13.4 m**. 밟은 범위(x −0.19~12.99)는 안 잘린다.

🔴 **④ 는 벽을 새로 그리지 않는다** — 관측한 적 없는 구조를 만들면 관제가 거짓말을 한다.
복도 밖을 **안 그릴** 뿐이다.

🔴 **⑤ 의 `OPERATION_AREA` 는 이 건물 좌표다.** 지도가 바뀌면 반드시 같이 고친다 = 예약 83.

**지도는 브라우저에 캐시한다.** `/map` 은 2초에 한 번 오므로 화면을 새로 열면 첫 지도가
도착할 때까지 비어 있다 — 촬영 첫 컷에서 그 공백이 그대로 찍혔다(09-04). 지도는 SLAM 이
끝나면 사실상 정적이므로 마지막 것을 `localStorage` 에 넣어 두었다가 즉시 그리고, 진짜
지도가 오면 덮어쓴다. 🔴 **사생활 보호 창은 저장소가 매번 비어 캐시가 듣지 않는다.**

## 이동거리는 '마지막으로 채택한 자세'에서 잰다

🔴 구판은 **직전 자세와 2 cm 미만이면 버렸다.** `/tf` 28 Hz · 0.17 m/s 면 한 번에 6 mm 라
문턱을 영영 못 넘어, 실제 **4.42 m** 를 달린 구간이 화면에 **0.1 m** 로 찍혔다
(realtake6 163~190초 대조 · 09-05 수정·검증). 기준점을 옮기는 방식이면 잔떨림은 그대로
걸러지면서 느린 이동이 누적된다. `PITFALLS §20-①`.

🔴 **탐지 수 MOCK 은 2026-09-04 에 삭제했다.** `사람 1 · 화재 1` 을 고정 상수로 띄웠는데,
연결복도처럼 아무것도 안 보이는 구간에서도 그대로 `1 / 1` 이라 **화면이 장면과 어긋나는
거짓말**을 했다. 지금은 실제로 온 것만 보여주고, 미결합은 `0 건` 이 아니라 **`미결합`** 이라고
적는다 — *"카메라가 봤는데 없었다"* 와 *"카메라가 없다"* 는 다른 사실이다.

🔴 **`/person_status` 는 08-23 bag 에서 상수 스텁이다** — `realtake6` 1,651건이 0초부터
끝까지 전부 `ok` 다. 카메라가 없어 `person_gate` 가 막히지 않게 띄운 것이고, **인지 결과가
아니다.** 화면의 `대피자 감지` 는 이 값을 그대로 보여주므로 영상·문서에서 *"사람을
인식했다"* 로 소개하지 않는다. 계약(`PROJECT_CONTEXT §4.1-b`)상으로는 어댑터가 발행하는
자리이므로 실물이 붙으면 진짜 값이 된다.
