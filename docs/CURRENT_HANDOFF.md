  재시작하면 `service_is_ready()` 는 계속 True 라 게이트가 두 세대를 구분할 수 없다.
  `lifecycle_msgs/GetState` 응답에 세대 식별자가 없어 **이 계층에서는 원리적으로 못 닫는다.**
  - **수용 전제**: Nav2 lifecycle 서버는 0.5s 안에 죽었다 살아나지 않는다(관리 노드가 순차 전이)
  - **재개방 조건**: R0~R2 실차에서 Nav2 노드 crash-restart 가 **1회라도** 관측되면 재개방
  - 부수 위험: `service_is_ready()` 가 매 폴링 깜빡이면 확인 수가 계속 0 으로 리셋돼 게이트가
    제한시간까지 못 찬다. fail-closed 방향이라 안전하지만 **기동 실패로 보인다** — R0 에서
    게이트 로그로 확인한다.
- E2E cleanup 순서 불변조건(부모 `ros2 launch` 먼저 kill → `pkill -9 -f "lib/nav2[_]"`, 브래킷 트릭 —
  `AGENTS.md §4`)은 회귀 실행 시 그대로 지킨다.
