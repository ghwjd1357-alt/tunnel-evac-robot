  선언이 없으면 '구동부 지연' 행을 발동한다. **판정을 미루지 않는다.**
- **★ 라이다 장착 높이 — 역할 A 가 흡수** (`MASTER_PLAN.md §7` 예약 11 ·
  `REAL_ROBOT_VALUES.md §4`) — 5번 요청해도 안 온 원인이 **미장착**이었다. **D+1 에 장착·측정**한다
  (`D1_FIRST_STEP.md §2`). ⚠ 브래킷·체결점 등 **기구 구조가 기구팀 소관이면 그 부분은 열려 있다.**
- **★ IMU 주기 조건부 수용 (08-01 · 08-02 갱신)** — 3차 회신 §5 실측이 **41.63Hz → 46.4Hz**
  (주기 20~23ms)로 갱신했고 EKF 여유가 3.33ms → 약 10.3ms 로 늘었다.
  ⚠ **23ms 도 상한이 아니다** — 관측 창 크기·표본 수가 또 빠졌다.
  **남은 재개방 조건 = R3 rosbag 최대 간격 33.33ms 초과** — 판정 도구 = `tools/bag_gap_report.py`.
  ⏸ 하네스(`gate_fakes.py`) 주기는 **아직 구값**이고 R3 때 한 번에 교체한다.
- **★ `/odom` 속도 +8.32% 는 열려 있다** — R2 는 **거리 기준으로만** 통과했고, 우리 EKF 는
  **속도만** 쓴다. 3m **소요시간**이 오면 (a) 실제로 빠름(≈139초) / (b) `/odom` 속도 부풀림
  (≈150초) 이 갈린다. **(b) 면 EKF 직격**이다. 최종 합의서 요청 4 로 요청했다.
- **★ 펌웨어 상한과 Nav2 순항속도가 같아졌다 (08-02 신설)** — `desired_linear_vel` 0.12 ·
  `rotate_to_heading_angular_vel` 0.5 가 **상한과 동일**하다. 곡선에서 동시에 걸리면 바깥 바퀴가
  잘리고 **잘림은 Nav2 에 보고되지 않는다.** **R6 에서 실제로 잘리는지 관측**하고 정한다.
- **★ 게이트 술어 불변조건** (`MASTER_PLAN.md §8` 07-30) — 조건 기동 게이트의 충족 판정은
  **"한 번 관측 = 통과" 금지**. 유효기간을 조이는 것은 보완이 아니다.
- **★ 세대 불변조건** (`MASTER_PLAN.md §8` 07-30) — **비동기 증거는 세대에 속한다.**
- **★ 증거 수집 불변조건 (07-30)** — 단언이 깨지는 순간의 증거는 **`fail()` 보다 먼저** 수집한다.
- **★ 외부 CLI 상한 불변조건 (07-30)** — `ros2` 든 `gz` 든 **예외 없이** hard 상한을 씌운다.
  **사람이 개입해서 얻은 PASS 는 판정이 아니다.** (`d0_check.sh` 도 이 규칙을 지킨다 —
  `python3 tools/scan_unbounded_cli.py tools/d0_check.sh` 출력 0건.)
- **★ 남은 검증 상한 (닫히지 않았다 — 조건부 수용)**: DDS 가 알아채기 전에(<1폴링) 서버가
  재시작하면 `service_is_ready()` 는 계속 True 라 게이트가 두 세대를 구분할 수 없다.
  - **수용 전제**: Nav2 lifecycle 서버는 0.5s 안에 죽었다 살아나지 않는다
  - **재개방 조건**: R0~R2 실차에서 Nav2 노드 crash-restart 가 **1회라도** 관측되면 재개방
- E2E cleanup 순서 불변조건(부모 `ros2 launch` 먼저 kill → `pkill -9 -f "lib/nav2[_]"`, 브래킷 트릭 —
  `AGENTS.md §4`)은 회귀 실행 시 그대로 지킨다.
