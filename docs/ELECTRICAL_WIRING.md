## 0. 작업 전 절대 규칙

1. 🔴 **배선을 만지기 전 `Jetson 정상 종료 → E-stop 누름 → XT90 분리 → 0V 확인 → 퓨즈 제거`.**
   E-stop은 모터 양극 가지만 끊으며 Wago·DCDC·Jetson·Teensy 전원은 끊지 않는다.
2. 🔴 **E-stop만 누른 상태에서 배선을 만지지 않는다.** 메인 차단 스위치는 없다.
3. 🔴 **배선을 하나라도 만지면 기존 E-stop 신뢰는 회수된다.** `§5-G6` 개폐 10/10과 필요한
   실기 배선 게이트를 다시 통과하기 전에는 지면 주행하지 않는다.
4. 🔴 **검은 음극선, 퓨즈 정격, 릴레이 단자 번호, 하네스 색을 추측하지 않는다.** 단자 각인과
   무전원 연속성 측정으로 식별한다.
5. 🔴 **Teensy는 3.3V 논리다.** PIN21 풀업 저항은 Teensy `3.3V`에만 연결한다.
   `25V`·`12V`·`5V`·`VIN`에 연결하면 안 된다.
6. 🔴 **LiPo 밸런스 커넥터에는 메인 퓨즈가 적용되지 않는다.** 금속 공구를 댄 채 다루지 않는다.
7. 🔴 **끼임 약 11A 상태의 의도적 E-stop 시험은 금지**다. 릴레이의 단독 25.2VDC 차단 정격은
   아직 증명되지 않았다.

## 1. 한눈에 보는 전체 계통

```text
                           ┌────────────── 모터 전력 ──────────────┐
[Tattu 6S LiPo]            │                                       │
  22.2V nominal            ▼                                       ▼
  25.2V max       XT90-S  [30A MAIN]  WAGO-P  RLY1  RLY2  WAGO-M+  MDD10A x2
  (+) 8AWG ────────●────────[ + only ]──●──────30/87─30/87──●──────B+
  (-) 8AWG ────────●─────────────────────┴ WAGO-N ─────────────────B-
                         │                    │
                         │                    ├── SD-50B-12 ── 12V ── Jetson DC jack
                         │                    └── SD-15B-5  ──  5V ── Teensy VIN
                         │
                         └─ [2A COIL] ─ LAZ16 C-NC ─ WAGO-C+ ─┬─ RLY1 coil
                                                                ├─ RLY2 coil
                                                                └─ RLY3 coil
                                                                     │
                                    Teensy GND ─ RLY3 30/87 ─ PIN21  │
                                    Teensy 3.3V ─ 3.3kΩ ──────┘      │

Jetson USB ───────────────────── data only ───────────────────── Teensy USB
Jetson USB ───────────────────── 5V + data ───────────────────── RPLIDAR C1

Teensy 3.3V/GND ── encoder x4 · BNO055
Teensy PWM/DIR/GND ── MDD10A x2 ── motor x4
```

🔴 위 그림의 핵심은 다음 세 가지다.

- E-stop은 **MDD10A 두 장의 공통 B+**만 릴레이 2개 직렬로 끊는다. 음극과 로직 전원은 유지된다.
- Teensy USB는 **통신 전용**이다. `VUSB–VIN` 트레이스를 절단했기 때문에 USB를 뽑아도 Teensy
  전원은 꺼지지 않는다.
- 현재 PIN21 외부 풀업은 설계안 330Ω이 아니라 **실물 3.3kΩ**이다. 470Ω(실측 467Ω)은 보관 중이며
  재개방 조건이 성립하기 전에는 바꾸지 않는다.

## 2. 전력 배선 — 배터리에서 각 부하까지

### 2.1 배터리·주 분배

| Net | 시작 → 끝 | 도체/부품 | 현재 상태와 주의 |
|---|---|---|---|
| `NET-BAT+` | 배터리 (+) → XT90-S/XT90 → 메인 퓨즈 입력 | 배터리 리드 8AWG, 연장 12AWG | ✅ 배터리 스트랩·단자 절연캡·XT90 뒤 스트레인 릴리프. **퓨즈 앞 구간은 무보호**라 가장 짧게 유지 |
| `NET-FUSED+` | 30A 퓨즈 출력 → 기존 Wago 221-415 (+) | 리드선형 홀더 12AWG, 접합 2곳 | ✅ 30A는 상한. 35/40A로 올리지 않는다. ⚠ 품번·시간-전류 곡선·DC 차단용량 미확인 |
| `NET-BAT-` | 배터리 (−) → XT90 → 기존 Wago 221-415 (−) | 8AWG → 12AWG | ✅ 음극에는 퓨즈 없음. **검은 가닥을 절단하지 않는다** |
| `NET-LOWV-SENSE` | 배터리 6S 밸런스 커넥터 → LiPo 알람 | 6S = 7선/7접점 | ✅ 셀당 3.5V 경보. 알람은 자동 차단기가 아니라 사람이 종료해야 하는 경고기 |

메인 30A 퓨즈가 직접 보장하는 범위는 **하드 단락 한정**이다. `30A < 14AWG 32A`라는 숫자만으로
부분 단락의 시간-전류 보호 협조가 증명되지는 않는다. 피복 마모·발열·Wago 변색을 발견하거나
퓨즈가 한 번이라도 끊어지면 `ELECTRICAL_BASELINE.md §3-c` 조건부 수용을 다시 연다.

### 2.2 모터 전력 가지

| Net | 시작 → 끝 | 도체/단자 | 기능 |
|---|---|---|---|
| `NET-MOTOR-SW+` 1 | Wago (+) → 릴레이1 `[30]` | 14AWG | 모터 양극 차단 사슬 입력 |
| `NET-MOTOR-SW+` 2 | 릴레이1 `[87]` → 릴레이2 `[30]` | 14AWG | 직렬 이중화 중간 |
| `NET-MOTOR+` | 릴레이2 `[87]` → Wago 221-415 → MDD10A #1/#2 `B+` | 14AWG | 두 드라이버 공통 차단 출력. 시공 때 계획안 221-413 대신 221-415 사용 |
| `NET-MOTOR-` | Wago (−) → MDD10A #1/#2 `B-` | 14AWG | 모터 귀환. E-stop이 끊지 않음 |
| `NET-MOTOR-OUT-*` | 각 MDD10A의 모터 출력 2채널 → 모터 4대 | 제조사 모터 리드/하네스 | ✅ 4륜 동작 확인. ❓ 출력 실크명·드라이버 번호·채널과 FL/RL/FR/RR의 물리 대응은 아직 정본 미확정 |

⚠ 릴레이 2개를 직렬로 둔 이유는 **하나가 융착돼도 다른 하나가 끊을 기회**를 남기기 위해서다.
“각 접점에 전압이 절반만 걸린다”는 논거는 철회됐다. 단일 융착이나 개방시간 차이가 있으면
남은 접점 하나가 최대 25.2V 전부를 끊어야 한다.

### 2.3 로직 전원 가지

| Net | 시작 → 변환기 → 부하 | 입력/출력 | 확인 상태 |
|---|---|---|---|
| `NET-JETSON-PWR` | Wago ± → Mean Well `SD-50B-12` → Jetson DC jack | 19~36VDC → 12V/4.2A | ✅ 무부하 출력 12.1V 확인 후 연결. ⚠ DC잭 종단의 실제 극성/커넥터 규격은 문서에 숫자가 없으므로 하네스 교체 전 실측 |
| `NET-TEENSY-PWR` | Wago ± → Mean Well `SD-15B-5` → Teensy `VIN/GND` | 18~36VDC → 5V/3A | ✅ 무부하 5.1V, Teensy 부하 5.0V, 3.3V 레일 정상 |
| `NET-USB-DATA` | Jetson USB → Teensy USB | USB CDC data only | ✅ `VUSB–VIN` 절단. USB 단독 미기동, VIN 단독 기동 확인 |

문서 일부에는 부품명이 `SD-15B-05`, 입력 하한이 19V로 남아 있다. 제조사 공식 모델명은
`SD-15B-5`, 입력은 18~36V이며, 21V 저전압 경보 정책은 더 보수적이라 바뀌지 않는다.

🔴 DCDC 입력 가지에는 현재 메인 30A만 있고 계획된 **12V 5A / 5V 3A 입력측 가지 퓨즈는
미설치**다. 카메라처럼 12V 부하를 추가하기 전에 `ELECTRICAL_BASELINE.md §8`의 ⑱을 먼저 닫는다.

## 3. E-stop 하드웨어 배선

### 3.1 코일 회로

```text
Wago (+)
  └─ 짧은 상류 리드 ─ [2A 유리관 퓨즈] ─ LAZ16 [C] ─ [NC] ─ Wago 221-415
                                                                ├─ RLY1 [86]
                                                                ├─ RLY2 [86]
                                                                └─ RLY3 [86]

RLY1/2/3 [85] ─ Wago 221-415 ─ NET-BAT-

각 코일 양단 1N5408:
  cathode(줄무늬) = [86] / anode(무줄무늬) = [85]
```

| 버튼 상태 | LAZ16 C-NC | 릴레이 1·2 | MDD10A B+ | 릴레이3 | PIN21 의미 |
|---|---|---|---|---|---|
| 해제(정상) | 닫힘 | 코일 ON, 30-87 닫힘 | 배터리 전압 | 코일 ON, 30-87 닫힘 | LOW = 정상 |
| 누름(정지) | 열림 | 코일 OFF, 30-87 열림 | 0V 목표 | 코일 OFF, 30-87 열림 | HIGH = 정지 |
| 코일선/2A 퓨즈 단선 | 열림과 동일 | 모터 B+ 차단 방향 | 0V 목표 | 접점 열림 | HIGH = 정지 |

✅ 2026-08-07 `0.05m/s` 부하 차단 10회에서 매회 0V, `/estop/state` 토글 10/10을 확인했다.
⚠ 이는 끼임 약 11A 차단이나 릴레이 제조사 정격 증명이 아니다.

### 3.2 PIN21 신호 회로 — 현재 실물

```text
Teensy GND ───────────── RLY3 [30]
                               [87] ───── Teensy pin 21
                                             │
Teensy 3.3V ───── 3.3kΩ ────────────────────┘

firmware:
  pinMode(21, INPUT_PULLUP)
  ESTOP_ACTIVE_LOW = false
```

| 사건 | 전기값 | 펌웨어 판정 | 고장 방향 |
|---|---:|---|---|
| 버튼 해제·접점 정상 | LOW | E-stop false | 주행 가능 조건 중 하나 |
| 버튼 누름 | HIGH | E-stop true | 정지 |
| `[87]→PIN21` 단선 | HIGH | E-stop true | 정지(fail-closed) |
| `[30]→GND` 단선 | HIGH | E-stop true | 정지(fail-closed) |
| 릴레이3 코일 단선 | HIGH | E-stop true | 정지(fail-closed) |
| 접점 순간 열림/브레드보드 접촉 불량 | HIGH 글리치 | 디바운스가 거절하거나 무장 해제 | 안전 쪽 실패지만 신뢰성 저하 |

현재 외부 풀업의 실물 상태:

| 저항 | 상태 | 접점 전류(근사) | 의미 |
|---:|---|---:|---|
| **3.3kΩ** | ✅ **현재 장착** | 약 1mA | 08-13 사용자 조건부 수용. 현 상태 유지 |
| 330Ω | ❌ 미장착 | 약 10mA | 과거 설계안. 실제 시험한 적 없음 |
| 470Ω(실측 467Ω) | ⏸ 보관 | 약 7mA | 재발현 3회 이상 + 만충 발현 시 만능기판 이관과 함께 검토 |

🔴 `3.3kΩ`을 `330Ω`으로 잘못 읽지 않는다. 색띠 한 칸 차이로 08-12에 실제 오인했다.
🔴 `/estop/state`와 `/drive/diag`는 1Hz라 짧은 글리치 수는 하한만 센다.

### 4.2 4륜 논리 순서

펌웨어 배열 순서는 항상 `FL, RL, FR, RR`이다.

| 논리 바퀴 | PWM/DIR | Encoder A/B | 전진 카운트 polarity |
|---|---|---|---:|
| FL(좌전륜) | 2 / 3 | 10 / 11 | +1 |
| RL(좌후륜) | 4 / 5 | 12 / 20 | +1 |
| FR(우전륜) | 6 / 7 | 14 / 15 | +1 |
| RR(우후륜) | 8 / 9 | 16 / 17 | +1 |

❓ 이 표는 **Teensy의 논리 계약**이다. 어느 MDD10A 보드의 어느 채널이 FL/RL/FR/RR인지,
모터 출력선 두 가닥의 색과 극성은 실물 사진/연속성 기록이 없어 확정하지 않는다. 하네스를
분리하기 전에 양끝 라벨과 사진을 먼저 남긴다.

## 5. 센서·통신 배선

### 5.1 엔코더 4개

각 엔코더는 `A`, `B`, `3.3V`, `GND` 네 선으로 본다.

| 항목 | 계약 |
|---|---|
| 신호 | 위 `§4.2` A/B 핀에 개별 연결 |
| 전원 | Teensy 3.3V 공유 |
| 기준 | Teensy GND 공유 |
| 전진 부호 | 네 바퀴 모두 전진에서 양수. FL은 2026-08-11 A/B 물리 교환 완료 |
| 미확인 | 엔코더 실소비 전류, 각 커넥터의 실제 선 색, 커넥터 핀 순서 |

전원이나 GND를 바꿔 꽂기 전에 엔코더 모델의 커넥터 핀아웃을 실물에서 확인한다. A/B 교환은
방향만 바꾸지만 3.3V/GND 오결선은 센서를 손상시킬 수 있다.

### 5.2 BNO055 IMU

| BNO055 | Teensy | 상태 |
|---|---:|---|
| VIN/3Vo 계통의 사용 중인 전원 입력 | 3.3V | ✅ 현재 3.3V 급전 계약. 보드 단자 명칭은 실물 확인 후 라벨링 |
| GND | GND | ⚠ 브레드보드 접점. 08-12 접점 요동과 반복 I2C 물림 이력 |
| SDA | 18 | 🔒 |
| SCL | 19 | 🔒 |

펌웨어는 주소 `0x28`을 먼저 시도하고 `0x29`도 지원한다. 현재 I2C는 100kHz다. IMU가 물리면
전원 재인가 후 약 3분 복구 절차를 쓰며, 단순히 GND 점퍼를 옮겨 생긴 일시 부활을 원인 확정으로
기록하지 않는다(`MASTER_PLAN §7` 예약 36).

### 5.3 MDD10A 제어 신호

각 모터 채널에는 Teensy의 PWM 1선과 DIR 1선이 들어간다. 두 MDD10A의 신호 GND는 Teensy GND와
공유돼야 한다. 이 선이 빠지면 명확한 단선 오류 대신 모터가 조용히 오동작할 수 있다.

| 연결 | 개수 | 현재 상태 |
|---|---:|---|
| PWM | 4 | 🔒 핀 2/4/6/8 |
| DIR | 4 | 🔒 핀 3/5/7/9 |
| signal GND | 드라이버별 필요 | ⚠ 실제 분기점·선 수·색 미기록. 브레드보드 사진 필요 |
| hardware enable/STO | 확인되지 않음 | 사용하지 않음. 그래서 공통 B+를 E-stop으로 끊음 |

### 5.4 Jetson USB 장치

| 장치 | 전원 | 데이터 | Linux 식별 | 상태 |
|---|---|---|---|---|
| Teensy 4.1 | SD-15B-5 → VIN | USB CDC → Jetson | `/dev/teensy_drive` | ✅ udev는 `16c0:0483` 제품군 기준. 두 번째 Teensy 연결 시 serial 조건 추가 필요 |
| RPLIDAR C1 | Jetson USB 5V | CP210x USB serial | `/dev/rplidar` | ✅ udev는 serial까지 고정. 런치 기본은 `/dev/ttyUSB0`이므로 `lidar_port:=/dev/rplidar` 인자 필요 |
| Orbbec Gemini 2 | ❓ 현재 미장착/미연동 | 향후 Jetson USB | 미정 | 계획 장치. 현재 배선표에 연결 완료로 올리지 않음 |
| PIM366 IR | 미연결 | Jetson 연결로 결정 | 미정 | 현재 사용하지 않음 |

⚠ RPLIDAR C1은 USB 5V라 12V DCDC 부하가 아니다. Gemini 2 또는 다른 12V 장치를 추가하려면
로직 가지 퓨즈와 전원 예산을 먼저 재판정한다.

## 6. 접지·절연 구조

현재 가장 중요한 전기적 경계는 “전력 GND”와 “신호 GND가 어디서 만나는가”다.

```text
배터리 (-) ─ Wago-N ─┬─ MDD10A #1/#2 B- ─ 큰 모터 전류 귀환
                      ├─ SD-50B-12 input-
                      └─ SD-15B-5 input-

SD-15B-5 output- ─ Teensy GND ─┬─ encoder/BNO055 GND
                               ├─ MDD10A signal GND
                               └─ relay3 [30]
```

사양상 SD 계열은 절연형으로 기록됐지만, 2026-08-13 무전원 측정에서 `SD-15B-5 output(-) ↔
input(-)`가 **1.23Ω**이었다. 따라서 현재 실물은 “완전히 분리된 두 접지”라고 가정하지 않는다.
모터 귀환 전류가 브레드보드 GND 레일이나 가는 점퍼를 지나면 접지 바운스가 생길 수 있다.

향후 만능기판/PCB 이관 원칙:

1. 모터 `B-` 귀환은 굵은 선으로 배터리 음극 분배점에 직접 돌아간다.
2. Teensy·센서 신호 GND는 별도 묶음으로 같은 기준점에 합류한다.
3. MDD10A signal GND에는 모터 부하 전류가 흐르지 않게 한다.
4. PIN21과 대응 GND는 한 쌍으로 가까이 배치한다.
5. PCB는 나일론 스탠드오프로 알루미늄 프레임에서 띄운다.
6. 헤더핀+듀폰 점퍼만으로는 진동 접촉 문제를 닫지 않는다. JST 등 락킹 커넥터 또는
   나사 터미널을 쓴다.

## 8. 배선 검사 체크리스트

### 8.1 매 기동 전 육안 검사

- [ ] 배터리 스트랩이 손으로 밀어도 움직이지 않고 단자 절연캡이 유지된다.
- [ ] XT90·메인 퓨즈홀더·Wago·릴레이 소켓에 열변색, 탄내, 헐거움이 없다.
- [ ] 2A 유리관 홀더가 Wago 가까이에 고정돼 있고 유리 균열이 없다.
- [ ] 릴레이1/2/3 `[87a]`와 LAZ16 `[NO]` 절연이 벗겨지지 않았다.
- [ ] 1N5408 세 개의 줄무늬 쪽이 모두 `[86]`이다.
- [ ] 브레드보드 점퍼가 빠지거나 한 칸 옆으로 이동하지 않았다.
- [ ] PWM/DIR·엔코더·IMU·PIN21/GND 선이 바퀴와 프레임 절단면에서 떨어져 있다.
- [ ] Teensy USB 케이블이 커넥터를 옆으로 당기지 않는다. 현재는 추가 스트레인 릴리프가 필요하다.
- [ ] 네 바퀴의 전진 방향을 모터 명령 전에 눈으로 확인한다.

### 8.2 배선을 만진 뒤

1. 무전원 상태에서 변경한 net의 시작·끝·인접 단자 단락을 확인한다.
2. 다이오드나 극성 부품을 만졌다면 방향을 다시 측정한다.
3. 바퀴를 공중에 띄우고 기동한다.
4. `tools/estop_toggle_check.py`로 **E-stop 개폐 10/10**을 확인한다.
5. 변경 범위가 안전 배선이면 `JETSON_SETUP §7-c-E` 또는 조건을 만족할 때 `§7-c-E2`를 다시 한다.
6. 모터·엔코더 하네스를 만졌다면 네 바퀴 방향과 전진 엔코더 양수도 다시 확인한다.
7. 결과와 사진을 같은 날짜 기록에 남긴다. 9/10은 통과가 아니다.

## 9. 기동·종료·고장 시 배선 관점 요약

### 9.1 기동

현장 순서 정본은 `CURRENT_HANDOFF.md`와 `JETSON_SETUP.md`다. 전기 관점의 순서는:

```text
퓨즈 확인 → XT90 연결 → Jetson 부팅 완료 → micro-ROS agent/런치
→ E-stop 누른 상태에서 Teensy 5V DCDC (+) 재인가
```

Teensy의 Program 버튼은 reset 버튼이 아니다. 애플리케이션 재기동은 E-stop을 누른 상태에서
5V DCDC의 Teensy `+` 전원을 재인가한다. USB 재삽입은 통신 재연결일 뿐 전원 재기동이 아니다.

### 9.2 종료

```text
모터 명령 종료 → Jetson sudo shutdown -h now → 완전 종료 확인
→ E-stop 누름 → XT90 분리 → 로봇 쪽 0V 확인 → 퓨즈 제거(정비할 때)
```

퓨즈홀더는 스위치가 아니다. 로직 전류가 흐르는 상태에서 퓨즈를 먼저 뽑지 않는다.

### 9.3 즉시 중단 조건

- 퓨즈가 한 번이라도 끊어짐
- E-stop을 눌러도 MDD10A B+가 0V가 되지 않음
- 릴레이 소리가 하나만 나거나 약해짐
- 릴레이·퓨즈홀더·Wago·전선의 발열, 탄내, 변색
- 배터리 부풀음, 피복 손상, 프레임 접촉 흔적
- `/estop/state`가 버튼 조작 없이 반복 상승하거나 IMU가 반복 사망
- USB reset/CDC 오류 또는 `/odom` timestamp 역행이 발현

이때 원인 확인 전 퓨즈 정격을 올리거나 디바운스/판정 창을 넓혀 증상을 숨기지 않는다.
