## 3. footprint 변환 계산

`가로 0.55`(폭, 좌우 = y) · `세로 0.57`(길이, 앞뒤 = x) → 중심 기준 절반:

```
시뮬(보존):  [[0.25, 0.20], [0.25, -0.20], [-0.25, -0.20], [-0.25, 0.20]]
실차(신규):  [[0.285, 0.275], [0.285, -0.275], [-0.285, -0.275], [-0.285, 0.275]]
               └ 세로/2 = 0.285      └ 가로/2 = 0.275     → 외접반경 √(0.285²+0.275²) ≈ 0.40m
```
